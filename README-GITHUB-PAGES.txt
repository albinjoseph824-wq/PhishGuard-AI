PHISHGUARD-AI — GITHUB PAGES EDITION

1. Upload ALL files in this folder to the root of your GitHub repository.
2. Make sure index.html is directly in the repository root.
3. GitHub repository -> Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, Folder: / (root), then Save.
6. Wait for the deployment and open the generated github.io URL.

This edition is static and does not require Flask/Python. URL analysis runs locally in the browser.
